# 新角色：职业装女性 · Blender 工作版

主要工程：`xuniren_working_v01.blend`。基于用户提供的 Maya/XGen 资源，保留源角色的身体、职业装、鞋子、配饰和发型方向。未覆盖之前的 Mitsuki 或凛工程，也尚未替换桌面程序中的模型。

## 已完成

- 从 Maya ASCII 中直接读取网格、UV、顶点编辑偏移和蒙皮数据；没有执行 Maya/MEL/Python 场景代码。
- 身体、西装外套、衬衫、裙子、鞋子、按钮、眼睛、口腔、眉毛及睫毛分别保留为对象。包括镜像和局部造型的 `.pt` 顶点偏移已转换。
- 转换了 259 个蒙皮影响骨骼/节点的参考绑定关系。保留源顶点权重，加入小幅转头检查动画（1–72 帧）。这不是原 Maya 完整控制器系统。
- 补充了眼球透明外层材质。眼镜作为可选配饰保留，工作版默认隐藏。
- 提取了 128 条原始 XGen 引导曲线，生成轻量发丝预览并保留原头皮网格作为底层。此发型是引导曲线插值重建，不是原始 XGen 求解结果。
- 工作版将贴图缩为最大 1024 像素并打包，减轻内存负担；原始高分辨率贴图和未缩图导入工程仍保留。

## 分组与使用

- `01_BODY`：身体、面部及骨架。
- `02_CLOTHING`：独立服装网格，沿用原文件 `xizhuang*` 名称。
- `03_XGEN_GUIDES_NOT_FINAL_HAIR`：原始引导曲线、头皮、眉毛/睫毛和重建头发。原始引导曲线默认隐藏。
- `04_ACCESSORIES`：耳饰、眼镜及其他配饰。
- `90_STAGE`：相机和灯光。

按空格播放转头测试；小键盘 0 切换相机视角。编辑前建议另存版本。服装可以独立隐藏、编辑，不必与身体合并。

## 当前限制

未转换 Maya 的复杂控制器、约束网络、校正 blendShape、完整表情和 XGen 密度/区域遮罩/发束求解。静态服装渲染及基础转头已检查，但尚未完成行走、布料/头发物理、自动换装和实时性能优化。头发轮廓与材质仍需精修。

`working-validation.json` 记录基础网格静止误差、小幅转头对身体及脚部的影响。它不是完整动作验收。

## 原始资源与脚本处理

原包完整保留在 `assets/source-models/xuniren-maya/XuNiren_jl/JL`。原 `.ma` 中检测到会写入 Maya 启动目录的脚本节点。另存了移除全部 6 个 script 节点的 `scenes/xuniren_Rig_NO_SCRIPT_NODES.ma`，没有运行原场景。此副本不是对未知 Maya 插件的安全认证；本工作流仅用白名单数据解析构建 Blender 文件。

可复现脚本：`modeling/import_xuniren.py`（源网格导入）、`modeling/finish_xuniren.py`（轻量工作版和预览）。脚本会覆盖对应生成版本；不要用它覆盖手工精修后的文件。
