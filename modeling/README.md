# 凛 · 学院风三维初模 v0.1

本轮已制作真实网格、独立服装、共用骨骼和基础表情形变。它是可编辑的程序化初模，尚未达到之前概念图的精细度；不是完成版数字人。

## 文件

- `assets/rin/rin_academy_v01.blend`：Blender 主工程，含学院风参考图、材质、分组、骨骼和工作室灯光。
- `assets/rin/rin_academy_v01.glb`：组合实时预览模型。
- `assets/rin/rin_base_v01.glb`：基础角色与骨骼，不含学院风衣服。
- `assets/rin/outfit_academy_v01.glb`：学院风网格与兼容骨骼。
- `assets/rin/manifest.json`：分件清单。
- `assets/rin/validation.json`：生成后的结构与基础变形检查。
- `previews/`：真实三维模型渲染，非 AI 概念图。

## 打开和预览

用现有的 Blender 5.2.1 打开 `.blend`。在 Outliner 中展开 `10_ACADEMY` 可以独立选择衣服。所有服装使用 `RIN_RIG` 的 Armature 修改器与同名顶点组，没有与身体合并。

在项目目录运行 `node scripts/preview-server.mjs`，然后打开 http://127.0.0.1:4317 。拖动旋转、滚轮缩放；右侧可显示隐藏外套、衬衫、褶裙、袜裤和鞋。整套开关保留基础角色。可检查基础转头动作、骨骼、线框和眨眼。

## 换装约定

保持角色比例、A 姿势、米制尺寸、骨骼名称与静止矩阵一致。新衣服使用独立网格，添加指向同一个 `RIN_RIG` 的 Armature 修改器，复制或绘制匹配权重。

独立导出的服装 GLB 带有参考骨骼。导入实时程序时应按骨骼名称与静止矩阵映射到角色的运行时骨架，不能只把衣服节点附到根节点上。当前预览使用组合 GLB，因此已经共用骨架；本轮仅制作学院风一套，并非四套服装都已建模。

`01_BODY` / `02_FACE` / `03_HAIR` / `04_ACCESSORIES` / `10_ACADEMY` 分别为身体、面部、头发、配饰与学院风衣服。基础身体无精细解剖细节，带打底层。

## 当前边界

- 头发由独立发片体块构成，需要继续细化轮廓、刘海衔接和材质；不是精修发型。
- 脸型、眼窝和表情仍是第一轮造型，不能称为原作高还原模型。
- 权重为初步 FK 绑定，只有小幅转头动作。还没有行走、坐下、IK、头发物理和布料模拟。
- 眨眼与 Talk 为基础形变试验，没有完整语音口型集。
- 当前裙子没有经过大幅腿部动作的防穿插处理；身体与衣服分离是后续换装的基础，不代表任意服装可自动适配。
- 目前是材质色块，没有完整手绘贴图与生产级 UV。
